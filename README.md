# EndGame Problem Solving — Sprint 1

A collection of 10 JavaScript problem-solving challenges provided by the EndGame Community as part of EG-13 Sprint 1.

All challenges are contained in a single JavaScript file:

EG-13_Sprint-1_PS.js

## 📚 Problems 01. Check if a Year is a Leap Year

Create a validation function that accepts an integer representing a calendar year and determines whether it is a leap year based on standard calendar rules.

Function: isLeapYear(year)

Expected Input: 2024

Expected Output: true

## 2. Generate Fibonacci Sequence Up to N Terms

Write a function that takes an integer n and returns an array containing the first n numbers of the Fibonacci sequence starting from 0 and 1.

Function: generateFibonacci(n)

Expected Input: 7

Expected Output:

[0, 1, 1, 2, 3, 5, 8]

## 03. Calculate the Greatest Common Divisor (GCD)

Implement a function that computes the Greatest Common Divisor of two non-negative integers using Euclid's algorithm.

Function: findGCD(a, b)

Expected Input: 48, 18

Expected Output: 6

## 04. Calculate the Least Common Multiple (LCM)

Construct a mathematical function that calculates the Least Common Multiple of two positive integers using their Greatest Common Divisor.

Function: findLCM(a, b)

Expected Input: 12, 18

Expected Output: 36

## 05. Check if a Number is Prime

Build a primality testing function that evaluates whether a given positive integer is a prime number.

Function: isPrime(num)

Expected Input: 29

Expected Output: true

## 06. Merge Two Sorted Arrays into One Sorted Array

Create a function that accepts two pre-sorted arrays of numbers and merges them into a single sorted array without re-sorting the combined result.

Function: mergeSortedArrays(arr1, arr2)

Expected Input:

[1, 3, 5], [2, 4, 6]

Expected Output:

[1, 2, 3, 4, 5, 6]

## 07. Find the Median of an Unsorted Array

Write a function that calculates the median value of an unsorted array of numbers. If the array length is even, return the average of the two middle elements.

Function: findMedian(nums)

Expected Input:

[7, 1, 3, 4, 9]

Expected Output: 4

## 08. Find the Second Largest Number in an Array

Construct an efficient scanning function that processes an unsorted array of numbers and extracts the second distinct largest element.

Function: findSecondLargest(nums)

Expected Input:

[10, 20, 4, 45, 99, 99]

Expected Output: 45

## 09. Find Most Frequent Element (Mode) in an Array

Develop a frequency detection function that identifies and returns the element that appears most often in an array.

Function: findMode(arr)

Expected Input:

[1, 3, 3, 2, 1, 3, 4]

Expected Output: 3

## 10. Natural Sorting of Strings with Embedded Numbers

Design a custom string array sorting function that handles natural numeric order inside strings, so "item2" comes before "item10".

Function: naturalSort(arr)

Expected Input:

["file10.txt", "file2.txt", "file1.txt"]

Expected Output:

["file1.txt", "file2.txt", "file10.txt"]
